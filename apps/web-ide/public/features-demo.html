Step 5: ONNX 384-dim Embeddings

🧠 ONNX MiniLM

OnnxMiniLmEmbedder (all-MiniLM-L6-v2) con 384 dimensioni. Qualità 3x migliore vs HashEmbedder(256).

CPU: Richiede AVX2 (Haswell+) | Fallback: HashEmbedder se unavailable

📦 Feature Flag

Compilato con --features onnx per includere ORT e tokenizers.

[features]
onnx = ["nexus-orchestrator/onnx"]

⚡ Performance

Embedding: 5-50ms | Throughput: ~100 embed/sec | Memory: ~200MB model

Step 6: CachedEmbedder (10k entries)

💾 Global Cache

Lazy static wrapper con 10k entry HashMap. Thread-safe con RwLock.

static TOOL_EMBEDDER_CACHE: Lazy<CachedEmbedder<HashEmbedder>>

⚙️ Latency

Hit: ~1ms | Miss: 5-50ms | Cache size: ~3-5MB (10k × 256-384d)

📊 Hit Rate

60-80% per semantic tool selection. Eviction: simple clear quando raggiunge max.
